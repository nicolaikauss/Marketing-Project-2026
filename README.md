# ESCP Marketing Project November 2026 · Naya Italy 2027

Go-to-market strategy and video ad for Naya's 2027 launch in Italy. Applied group project for the ESCP Bachelor marketing course (MK21, Turin). Group leader: Nicolaï Kauss.

Two parts:

1. **Go-to-market deck**: `deck/project/` (20 slides, one HTML file per slide, order in `deck.json`). PDF export in `outputs/`.
2. **Video ad**: `ad/` (Remotion). Renders in `outputs/`: 60s 9:16 (IT), 60s 9:16 (EN), 30s 9:16, 16:9 landscape.

## Run the ad locally

```console
cd ad
npm i
npm run dev
```
